# FloodSenseAI 🌊

FloodSenseAI is an AI-powered flood risk prediction and environmental analysis platform that helps users assess flood danger levels using real-time environmental and weather data.

The platform combines:
- AI reasoning
- Weather forecasting
- Elevation analysis
- River proximity analysis
- Interactive maps
- PDF report generation

to provide an intelligent flood risk assessment system.

---

## 🚀 Features

- Interactive Google Maps coordinate selection
- Real-time flood risk prediction
- Weather and forecast analysis
- Elevation and river-distance analysis
- AI-generated flood reasoning insights
- Prediction history storage
- Export professional PDF reports
- Responsive modern UI
- Location-based environmental assessment
